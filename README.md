# Medical Esthetics Thunder Bay Operations

Private internal operations repo for Medical Esthetics Thunder Bay.

## Purpose
This repository is used to organize:
- sales growth systems
- client communication workflows
- vendor communication
- package and membership optimization
- Shopify storefront launch tasks
- inventory management
- bill tracking and operational accountability
- monthly KPI monitoring

## Main Goal
Increase monthly revenue from approximately $60,000 to $150,000 through:
- improved lead conversion
- stronger client retention
- upselling and cross-selling
- better package design
- membership optimization
- improved inventory controls
- Shopify launch and product sales
- tighter vendor coordination
- better financial systems and accountability

## Important Rules
- This repository must remain private.
- Do not store passwords, credit card numbers, banking credentials, or PHI in this repo.
- Use a password manager for credentials.
- Use placeholders and secure references only.
- All client communication must remain professional, brand-aligned, and compliant.
