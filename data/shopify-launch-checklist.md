# Shopify Launch Checklist — Medical Esthetics Thunder Bay

> Last updated: 2026-03-19
> Work through this checklist before going live. Check off each item when complete.

---

## 1. Store Setup

- [ ] Store name and URL confirmed
- [ ] Brand logo uploaded (high-res, PNG with transparent background)
- [ ] Brand colors and fonts applied to theme
- [ ] Favicon uploaded
- [ ] Homepage hero section written and styled
- [ ] About / Our Story page drafted
- [ ] Contact page with correct phone, email, and location
- [ ] Privacy policy added (Shopify auto-generate or custom)
- [ ] Terms of service added
- [ ] Refund / return policy added and compliant with clinic policy
- [ ] Footer links and social media icons connected

---

## 2. Products & Collections

- [ ] All retail skincare products added with:
  - [ ] Professional product photos
  - [ ] Luxury product copy (benefits-led, outcome-focused)
  - [ ] Correct pricing in CAD
  - [ ] Variants (sizes, quantities) configured if applicable
  - [ ] SKU and inventory count entered
- [ ] All supplements / wellness products added
- [ ] Gift cards added
- [ ] Collections created:
  - [ ] Skincare
  - [ ] Supplements
  - [ ] Bundles & Packages
  - [ ] New Arrivals
  - [ ] Best Sellers

---

## 3. Bundles & Offers

- [ ] At least 1 product bundle live (e.g. AM/PM skincare set)
- [ ] Welcome offer or first-order discount configured
- [ ] Gift with purchase (if applicable) set up

---

## 4. Payments & Checkout

- [ ] Payment gateway connected and tested (Shopify Payments / Stripe)
- [ ] Test transaction completed and refunded
- [ ] Taxes configured for Ontario / Thunder Bay
- [ ] Shipping zones and rates set (local pickup option added)
- [ ] Checkout branding matches clinic brand

---

## 5. Integrations

- [ ] Email marketing integration connected (Klaviyo / Mailchimp / Shopify Email)
- [ ] Abandoned cart recovery emails enabled
- [ ] Post-purchase thank you email configured
- [ ] Google Analytics or Meta Pixel connected
- [ ] Instagram Shopping connected (if applicable)
- [ ] EMR / booking software linked or referenced

---

## 6. SEO & Copy

- [ ] Homepage title tag and meta description written
- [ ] All product pages have meta descriptions
- [ ] Page URLs are clean and keyword-relevant
- [ ] Alt text added to all product images
- [ ] Blog section set up (optional — for SEO and trust)

---

## 7. Mobile & Speed

- [ ] Store fully reviewed on mobile device
- [ ] All images optimized (compressed, fast-loading)
- [ ] Navigation is intuitive on mobile

---

## 8. Pre-Launch Review

- [ ] All links tested (no broken links)
- [ ] All prices correct
- [ ] All product descriptions reviewed and on-brand
- [ ] Password page removed (store set to public)
- [ ] Domain connected and SSL active
- [ ] Team members notified of launch date

---

## 9. Launch Announcement

- [ ] Launch social media posts scheduled
- [ ] Email to existing client list drafted and scheduled
- [ ] In-clinic signage or prompts added
- [ ] Staff briefed on how to direct clients to the store
